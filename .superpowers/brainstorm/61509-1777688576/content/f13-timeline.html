F13 — What goes in the Timeline tab?

The other tabs are clear (Leases = lease table, ECL = ECL breakdown, Scenarios = sensitivity). Timeline is the design question.

A

Event log — table of credit events

A chronological table of significant events: payments (on-time, late, missed), rating changes, stage transitions, SICR triggers, deferrals, watchlist additions. Each row has a date, event type (colour-coded), description, and impact.

DateEventDetail
2026-03-14 Late Payment 45 DPD · $285k rent · LSE-2019-001
2026-02-01 Stage → 3 SICR backstop: 30+ DPD triggered
2025-12-10 Rating ↓ S&P: BBB- → BB-

✓ Audit-trail friendly. Easy to read. Covers multiple event types.

B

Payment-lateness chart over 12 months

A bar/area chart showing days-overdue per month (or days paid early as negative). Key events annotated on the chart (rating change, stage transition). Gives an immediate visual read on trajectory.

OctNovDecJanFebMar
▲ Stage 3 transition · Feb 2026

✓ Instant visual read on deterioration. ✗ Less detail per event.

C

Chart at top + event log below

Best of both: a compact 12-month days-overdue sparkline with annotated stage/rating events at the top, then the full event log table below. The chart provides trajectory at a glance; the log provides auditability.

Event log below ↓ (Late Payment · Stage → 3 · Rating ↓ · ...)

✓ Most complete view. Slightly taller tab content — fine given available space.
