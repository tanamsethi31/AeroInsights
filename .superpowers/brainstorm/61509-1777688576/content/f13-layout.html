F13 — Where does the new content live?

Three ways to add Lease Breakdown, ECL Attribution, Payment History, and Scenario Sensitivity

A

Tabs in the profile panel

The right-hand detail area gets a tab strip: Overview | Leases | ECL | Timeline | Scenarios. The existing radar + KPI cards become the "Overview" tab. New content fills the other tabs.

Overview Leases ECL Timeline Scenarios
Existing radar + restructuring stay here as Overview

✓ Clean — no scrolling. Consistent with Portfolio pattern.

B

Scroll-down sections below existing cards

Keep the current layout intact. After the Restructuring Simulator, add new collapsible sections: Lease Breakdown, ECL by Lease, Payment History, Scenario Sensitivity. Each can expand/collapse.

▸ Behavior Score · Days Overdue [KPI cards]
▸ Radar chart + Restructuring Simulator
▸ Lease Breakdown ↓ [new]
▸ ECL Attribution ↓ [new]
▸ Payment Timeline ↓ [new]

✓ No migration needed. ✗ Long scroll — content gets buried.

C

Full-page deep-dive (separate view)

Clicking a lessee navigates to a dedicated full-width profile page. The sidebar list disappears; the deep-dive takes the whole canvas with a richer layout — header banner, 4-KPI strip, tabs, timeline, and a larger chart area.

Leases | ECL | Timeline | Scenarios tabs below

✓ Most real estate. ✗ Requires routing change or modal — higher complexity.
